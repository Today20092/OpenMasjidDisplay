# Triage labels

| Role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | `needs-triage` | Maintainer needs to evaluate the issue |
| needs-info | `needs-info` | Waiting for information from the reporter |
| ready-for-agent | `ready-for-agent` | Fully specified work an agent can perform independently |
| ready-for-human | `ready-for-human` | Work or a decision requiring a human |
| wontfix | `wontfix` | Will not be actioned |

New requests start with `needs-triage`. Replace the triage role as the issue changes state. Wayfinder type labels describe the kind of decision and can coexist with a triage role. A blocked decision is not ready merely because its question is written.
