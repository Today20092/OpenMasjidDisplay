## Discovery and documentation

Discover code through codebase-memory-mcp. Index the repository if necessary, search symbols, trace callers and callees, then fetch source snippets. Fall back to text search for non-code files, literals, or an insufficient graph.

Fetch current library, framework, SDK, API, and CLI documentation through Context7: resolve the library, then query each relevant concept. Cite the fetched documentation when recommending technology.
